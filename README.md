Мониторинговая система на базе Docker Compose

Данный проект представляет собой инфраструктуру для мониторинга PostgreSQL и системных метрик с использованием современных инструментов. 

Обзор системы


Система включает следующие компоненты:

| Сервис              | Назначение                              | Версия    |   Порт   |
|---------------------|-----------------------------------------|-----------|----------|
| PostgreSQL          | Основная база данных                    | 15-alpine | 5432     |
| pgAdmin             | Веб-интерфейс для управления PostgreSQL | 9.0       | 8080     |
| Grafana             | Визуализация метрик и дашборды          | latest    | 3000     |
| Prometheus          | Сбор и хранение метрик                  | latest    | 9090     |
| Postgres Exporter   | Экспорт метрик PostgreSQL               | latest    | 9187     |
| Node Exporter       | Экспорт системных метрик                | latest    | 9100     |


## Технические требования

Перед началом убедитесь, что на вашем компьютере установлено:
- Docker 20.10.13 или новее
- Docker Compose 2.12.0 или новее
- 4 ГБ свободной оперативной памяти
- 2 ГБ свободного места на диске




Шаги для запуска:
1. Скачайте репозиторий на локальную машину
2. Запустите сборку образа (cmd), выписывая команду от директории, в которой сохранён репозиторий: docker-compose up -d --build 
    2.1. Для последующих запусков используйте графический интерфейс Docker или (cmd): docker compose up -d
3. Перейдите на localhost:... , введя его в строке браузера (...- номер порта сервиса)




Проверьте версии:
```bash
docker --version
docker-compose --version
